# Scenario 01 — ICMP Ping Detection

## Objective
Detect ICMP echo requests sent from the Kali Linux attacker VM to the Ubuntu monitoring host using Suricata, and verify that the resulting alert is forwarded to Wazuh.

## Systems
- Attacker: Kali Linux — 192.168.23.133
- Target/Sensor: Ubuntu 24.04 — 192.168.23.131
- IDS: Suricata 8.0.0
- SIEM: Wazuh 4.12.0

## Detection Rule
alert icmp any any -> $HOME_NET any (msg:"LAB ICMP Ping Detected"; itype:8; sid:1000001; rev:1;)

## Attack Simulation
From Kali Linux:

```bash
ping -c 5 192.168.23.131

## Observed Result
The test successfully triggered the custom Suricata rule.

- Suricata SID: `1000001`
- Source: `192.168.23.133` (Kali Linux)
- Destination: `192.168.23.131` (Ubuntu)
- Alert: `LAB ICMP Ping Detected`
- Wazuh Rule ID: `86601`
- Wazuh Rule Level: `3`

The alert was generated by Suricata, written to `eve.json`, collected by the Wazuh agent, and successfully displayed in the Wazuh dashboard.
